      A small app can solve a real problem

      You do not have to begin with a big software idea. Begin with one useful job and make that job easier.

      Look for a decision, calculation, repeated task or confusing process that people would value help with.

      2

      Make the result useful

      Decide what someone should leave with: an answer, a plan, a comparison, a score or a ready-to-use resource.

      3

      Build the smallest version

      Start with the essential questions, logic and result. Test it with real people before adding more features.
